# Trevor McDonald — Portfolio

Static site for GitHub Pages. No build step.

## Publish on GitHub Pages
1. Create a repo named `trevor-mcdonald.github.io` (public).
2. Upload everything in this folder (index.html, resume.pdf, img/) to the repo root.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site goes live at `https://trevor-mcdonald.github.io` within a minute or two.

## Updating
- Replace `resume.pdf` with your latest resume (same file name).
- Add photos to `img/` and reference them in index.html.
- Search index.html for `TODO` to find placeholders (e.g. the Neato repo link).
